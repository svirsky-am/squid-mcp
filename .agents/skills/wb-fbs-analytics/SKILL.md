# Навык аналитики Wildberries FBS и управления отчётами

Используй этот навык, когда пользователь задаёт вопросы о заказах, выручке, статусах сборочных заданий FBS на Wildberries или просит выгрузить сводный `.xlsx`-отчёт на Google Диск.

## Доступные инструменты MCP (`wb-alice-server`)

1. **`get_orders_summary(days: int = 7)`** — сводка по количеству заказов и сумме выручки в рублях за последние `N` дней в разрезе статусов продавца и статусов WB.
2. **`get_top_articles(days: int = 30, limit: int = 5)`** — рейтинг лучших артикулов продавца по выручке за `N` дней (без учёта отменённых заказов).
3. **`get_cancellations_stats(days: int = 30)`** — статистика отмен и отказов покупателей по артикулам с суммой упущенной выручки.
4. **`find_order_by_id(order_id: int)`** — детальная карточка конкретного сборочного задания FBS по его числовому ID (дата создания, артикул, `nmId`, `SKU`, цена, номер поставки и актуальные статусы).
5. **`upload_latest_report_to_drive(filename: str | None = None)`** — загрузка последнего (или указанного по имени) сводного Excel-отчёта в папку Google Диска и возврат прямой ссылки `webViewLink`.
6. **`sync_product_cards()`** — принудительно обновляет справочник карточек товаров из Content API WB (названия, бренды, категории, баркоды). Вызывай, если пользователь просит «обнови карточки товаров» или «синхронизируй справочник».
7. **`get_product_card_info(query: str)`** — ищет карточку товара в локальной базе по артикулу продавца, названию или `nmID`.

---

## Правила выбора инструмента

* **Общие вопросы («как дела с продажами», «сводка за неделю/месяц», «сколько заказов на сборке»):**
  Вызывай `get_orders_summary(days=...)`, переводя период пользователя в дни (`сегодня/вчера` → `1` или `2`, `неделя` → `7`, `месяц` → `30`).
* **Вопросы о лидерах продаж («топ товаров», «что лучше продаётся»):**
  Вызывай `get_top_articles(days=..., limit=...)`.
* **Вопросы об отменах и браке («сколько отмен», «почему упала выручка», «проблемные артикулы»):**
  Вызывай `get_cancellations_stats(days=...)`.
* **Запрос по конкретному номеру («проверь заказ 13833711», «статус задания ...»):**
  Извлеки числовой идентификатор и вызови `find_order_by_id(order_id=...)`.
* **Запрос на выгрузку файла («скинь отчёт», «выгрузи таблицу на гугл диск», «обнови excel на диске»):**
  Вызывай `upload_latest_report_to_drive()` и обязательно передай пользователю полученную ссылку `webViewLink`.

---

## Требования к формированию ответа

1. **Только факты из БД:** никогда не выдумывай цифры, артикулы или статусы. Если инструмент вернул пустой результат, прямо сообщи, что за выбранный период данных в локальной базе нет.
2. **Единицы измерения:** суммы всегда указывай в рублях (`₽`), количество товаров и заказов — в штуках (`шт.`).
3. **Формат подачи:** отвечай кратко и структурированно — в виде маркированного списка или компактной сводки, удобной для чтения в чате Алисы.
