# Навык аналитики Wildberries и управления отчётами

Используй этот навык для ответов на вопросы о продажах, заказах FBS, остатках, конверсиях карточек и для выгрузки многостраничного `.xlsx`-отчёта на Google Диск.

## Доступные инструменты MCP (`wb-alice-server`)

### Заказы FBS и выручка
1. **`get_orders_summary(days: int = 7)`** — сводка по заказам FBS, статусам сборки/доставки, общей выручке в рублях и топ-3 товара за последние `N` дней.
2. **`get_top_articles(days: int = 30, limit: int = 5)`** — рейтинг лучших товаров и артикулов по выручке за `N` дней с названиями и категориями.
3. **`get_cancellations_stats(days: int = 30)`** — статистика отмен и отказов покупателей по артикулам с суммой упущенной выручки.
4. **`find_order_by_id(order_id: int)`** — детальная карточка конкретного сборочного задания FBS по числовому ID.

### Карточки товаров
5. **`get_product_card_info(query: str)`** — поиск карточки товара в локальной базе по артикулу продавца, названию или `nmID`.
6. **`sync_product_cards()`** — принудительное обновление справочника карточек товаров из Content API WB.

### Остатки на складах FBS и прогноз дефицита
7. **`get_fbs_stocks(query: str | None = None)`** — актуальные остатки товаров на складах продавца (все позиции или поиск по артикулу/названию/SKU).
8. **`get_low_stock_forecast(days_threshold: int = 7, lookback_days: int = 14)`** — прогноз обнуления остатков: расчёт темпа продаж и список товаров, которых хватит меньше чем на `days_threshold` дней.
9. **`sync_fbs_stocks()`** — принудительное обновление складов и остатков FBS из WB API.

### Воронка продаж и конверсии
10. **`get_sales_funnel_summary(days: int = 7, limit: int = 5)`** — сводка воронки продаж за период: переходы в карточки, добавления в корзину, заказы, выкупы, проценты конверсии и топ карточек по просмотрам.
11. **`sync_sales_funnel(days: int = 7)`** — принудительная выгрузка свежей статистики воронки продаж из Seller Analytics API WB.

### Отчёты Google Диска
12. **`upload_latest_report_to_drive(filename: str | None = None)`** — загрузка последнего (или указанного) 6-страничного Excel-отчёта в папку Google Диска и возврат прямой ссылки `webViewLink`.

## Правила выбора инструмента

* **Общие вопросы («как дела с продажами», «сводка за неделю/месяц», «сколько заказов на сборке»):**
  Вызывай `get_orders_summary(days=...)`, переводя период пользователя в дни (`сегодня/вчера` → `1` или `2`, `неделя` → `7`, `месяц` → `30`).
* **Вопросы о лидерах продаж («топ товаров», «что лучше продаётся»):**
  Вызывай `get_top_articles(days=..., limit=...)`.
* **Вопросы об отменах и браке («сколько отмен», «почему упала выручка», «проблемные артикулы»):**
  Вызывай `get_cancellations_stats(days=...)`.
* **Запрос по конкретному номеру («проверь заказ 13833711», «статус задания ...»):**
  Извлеки числовой идентификатор и вызови `find_order_by_id(order_id=...)`.
* **Запрос на выгрузку файла («скинь отчёт», «выгрузи таблицу на гугл диск», «обнови excel на диске»):**
  Вызывай `upload_latest_report_to_drive()` и обязательно передай пользователю полученную ссылку `webViewLink`.

## Правила выбора инструмента и форматирования

1. **Никаких выдуманных цифр:** опирайся строго на данные инструментов MCP. Если данных за период нет, предложи пользователю запустить соответствующий инструмент синхронизации (`sync_...`).
2. **Единицы измерения:** суммы указывай в рублях (`₽`), количество — в штуках (`шт.`), конверсии — в процентах (`%`).
3. **Компактный формат:** оформляй ответы списком, удобным для чтения в чате Яндекс Алисы.
